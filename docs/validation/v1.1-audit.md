# v1.1 integration audit and execution record

Date: 2026-10-20. Baseline: main commit `d8dc5b1f90b32159c7d3aece69e3af12c5cfc24f`.

## Findings from the completeness audit

The previous release had all 61 source module names, but only broad Cxx mappings. It did not expose each module's distinct facets, a feature-level complement map, a README plain-text tree or a queryable gap-to-repair route. Guided review and calibration had no named route. Numeric single-source generation and local bibliography lookup were described workflows rather than implemented helpers. Revision progress terminology could be confused with the machine `issue.status` enum.

The update adds 61 Fxxx source-feature records with 227 explicitly named facets; each has protocol paths, complements, a representative micro-case and a current source-body hash. Thirteen repositories are represented. Useful source concepts are rewritten into the existing 36 capabilities; a 13th protocol adds guided review, target-criteria binding, calibration and separate author/editor channels. The runtime has 11 modes and new locate, policy, calibration, numeric-macro and local bibliography commands.

Two missing complement edges were caught in the first full new test run and added. Macro-generation syntax, precise percentage-point unit spelling and inadequate acceptance descriptions were also corrected during implementation. An additional CLI smoke check found over-broad exact-ID search results; exact capability, feature, module and gap queries now stay focused, with regression assertions. These are implementation repairs, not evidence that all scientific review errors have been eliminated.

## Source coverage versus implementation parity

All declared modules have feature records. This is a complete accounting of the chosen 61-module inventory, not a claim that every optional upstream executable or dependency was ported. Source-specific service adapters, general inferential statistics, document compilers and broad visual understanding remain host integrations or open development tasks. Their exact entry points are in [EXTENSION_INDEX.md](../EXTENSION_INDEX.md).

The source-body fingerprints were refreshed from public files. No upstream text or code is redistributed. Reading a main skill file does not exhaust its subordinate scripts/references. Fixed flaw counts, punctuation-based severe findings, universal bitmap rejection, uncalibrated acceptance odds, prestige-based research scoring and promotional citation requirements were not adopted.

## Conflict comparison

[58 fixed cases](../../tests/fixtures/conflicts/cases.json) cover all 16 conflicts. [compare_policies.py](../../scripts/compare_policies.py) runs both explicit operationalizations on the same records. Selected rules match 58/58 expected decisions; deliberately strict/simple alternative rules match 13/58. [Actual output](conflict-comparison.json).

The alternatives implement the named conflicting heuristics, for example raw numeric equality, fixed issue quotas, every row as an independent sample, every raster as a failure, and accepting a textual passed claim for closure. They are not runs of the upstream skills or their models. Cases and labels were authored for regression, not sampled from an independent paper benchmark. These counts justify these concrete rule choices on these cases; they are not model accuracy or a universal superiority estimate.

CFX01 actually loads and recomputes source numbers. CFX16 actually invokes evidence-anchored recheck. Other policy rules operate on structured reviewer-supplied facts, such as identified study type or semantic inventories. The caller must first establish those facts from the manuscript. Accordingly, broad semantic conflict states remain partial in the original register even though the structured regression checks pass.

## Real-paper effect

The [ReAct review](real-react-review.md) used an actual public paper and rendered page inspection, not just the old fictional manuscripts. It provides a usable English replacement for improvement wording, recomputes five table differences, rejects a relative-percent error probe, preserves different evaluation subsets and avoids a blanket zero-axis demand. It does not manufacture author mistakes to satisfy a flaw quota.

The paper PDF and source-skill bodies are analysis inputs, not vendored repository files. Published aggregate values are stored as small, attributed transcriptions. No raw experiment runs or model training were reproduced.
