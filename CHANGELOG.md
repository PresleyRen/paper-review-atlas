# Changelog

## 1.0.0 — 2026-10-20

Initial public release of Paper Review Atlas.

- Added 36 capability entries, 12 specialist protocols and 9 composable review routes.
- Added Chinese/English writing, experiments/statistics, figures/tables, theory, citations, reproducibility, Agent profiles, adversarial adjudication, revision and rebuttal workflows.
- Added exact quote anchors, Decimal-based CSV/JSON reconciliation, paired descriptive summaries, evidence-record validation and revision rechecks.
- Added safe project installation, backup outside active discovery, portable package validation and GitHub Actions checks.
- Added a 13-repository / 61-module conceptual source inventory and 16 explicit conflict policies.
- Added generated SVG, Mermaid and Markdown coverage maps, bilingual README files, CLI reference and an extension roadmap.
- Added rule/integration tests, two full bilingual synthetic forward reviews, a clean bilingual writing control, and executable failed/passed recheck examples.
- Fixed pre-release declaration precision loss, invalid recheck exit classification, recursive install overlap, and duplicate skill discovery from backups.

Validation scope and remaining gaps are documented in `docs/VALIDATION.md`; this release does not claim calibrated review accuracy or independent expert equivalence.
