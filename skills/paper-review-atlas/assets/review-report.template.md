# Paper Review Atlas — 审查报告 / Review report

## 1. Scope and contribution / 审查范围与贡献

Paper/version; task mode; discipline; language; target venue and source date if known.
Briefly state the research question, actual contribution and principal uncertainty.
Record actual reviewer/model provenance. Do not invent independence or acceptance odds.
